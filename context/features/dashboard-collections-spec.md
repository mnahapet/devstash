# Dashboard Collections Spec

## Overview

Replace the dummy collection data displayed in the main area of the dashboard (right side), with actual data from our Neon database using Prisma. 

Do not add the items underneath yet. We will do that later.

## Requirements

- Create src/lib/db/collections.ts with data fetching functions
- Fetch collections directly in server component
- Collection cards have a proportional color strip on the left based on item type distribution
- Keep the current design. You can also reference the screenshot
- Update collection stats display
- Pagination should be handled on the client side
